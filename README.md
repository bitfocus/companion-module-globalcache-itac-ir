This is always the newest working version, ready to import into Companion.

**To install it:**
1. Click the download link above.
2. On the page that opens, under **Assets**, click the file ending in **.tgz** to download it.
3. In Companion, go to **Modules** and click **Import module package**, then choose that file.
4. In your Global Cache connection, pick the new version from the version list.

You can switch back to the built-in version at any time.

This is an improved version of the Bitfocus Companion module for Global Caché iTach IR interfaces (IP2IR, WF2IR), focused on reliability in live production. It has been submitted to Bitfocus to become the official version.

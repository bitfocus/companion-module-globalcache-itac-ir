First full release of the improved module, replacing the 3.0.0 test versions.

- Reconnects by itself after network drops, power cuts or an iTach reboot, and shows the real connection state.
- Notices when an iTach stops answering (for example a PoE switch port or Wi-Fi dropping) and reconnects before the next button press.
- Sends codes one at a time per port and waits for the iTach to confirm each one, so quick presses are never cut off.
- Never fires a power toggle late or twice after an outage.
- Accepts codes pasted straight from iLearn, and explains clearly when a code is wrong.
- New: repeat count, Stop IR, hold-to-repeat buttons, status button, and connection/failure indicators.
- Existing buttons and codes keep working without changes.
